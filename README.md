## Описание
Это простое приложение "чат" с клиентом на PySide6 и сервером на FastAPI.  
Клиент отправляет сообщения на сервер и получает список сообщений.  

Сначала запустить сервер:

dist\server\server.exe

Затем запустить клиент:

dist\client.exe

Важно: сервер должен быть запущен до клиента.

Примечания

Сервер использует SQLite (test.db)

API доступно по адресу: http://127.0.0.1:8004

Клиент обращается к серверу по http://127.0.0.1:8004
